🌐 Remote API 端点 (当前分支特性)

方法路径说明
GET /health 健康检查 (无需认证)
GET /health/detailed 详细健康状态 + 统计
GET /v1/models 列出可用模型
GET /v1/capabilities 能力标志 (Hermes 格式)
POST /v1/chat/completions Chat Completions API (OpenAI 兼容)
POST /v1/responses Responses API (OpenAI 兼容)
GET /v1/responses/{id} 获取存储的响应
GET /v1/responses/{id}/input_items 获取响应的输入项
DELETE /v1/responses/{id} 删除存储的响应
